margay watches your

what it does

One pass over
your tree.

margay walks your project — respecting .gitignore — and prints a focused report of every permission bug it finds. Output is grouped by category and shows the exact mode change needed.

Run it naked to audit. Add --fix to patch in place. Exit code is non-zero on findings, so CI catches it too. 

$ margay
Sensitive files too open
  !! ./.env              0644 → 0600

Shell scripts missing +x
  +x ./scripts/deploy.sh  0644 → 0744

Source files marked executable
  -x ./src/main.rs        0755 → 0644

✗ 3 issues found across 3 files
# run with --fix to patch all

what margay sees

Three permission bugs
that quietly ruin your week.

001 / exec bits

Scripts that forgot to be executable.

You wrote deploy.sh on Windows. You committed it. CI runs it. CI dies with permission denied. margay flags every shell script missing the user-execute bit so you can patch them before the pager fires. 

$ margay
Shell scripts missing +x
  +x scripts/deploy.sh    0644 → 0744
  +x scripts/migrate.sh   0644 → 0744

$ margay
Sensitive files too open
  !! .env              0644 → 0600
  !! secrets/api.key   0664 → 0600

002 / loose secrets

Secrets sitting at 0644.

Every .env, *.key, *.pem, and id_rsa in your tree should be 0600 or stricter. margay finds the ones that aren't — then runs chmod for you with --fix.

003 / accidental exec

Source files marked executable.

A stray chmod -R 755 turns README.md and every *.rs into "executables." Harmless, embarrassing, and a permanent eyesore in git status. margay catches them. 

$ margay --fix
margay: fixed 5 issue(s)

$ margay
✓ no permission issues found

quick start

Install and audit
in under a minute.

01.

Install with cargo

$ cargo install --git https://github.com/iamkorun/margay

Requires Rust 1.70+. Single binary, no runtime.

02.

Or build from source

$ git clone https://github.com/iamkorun/margay.git
$ cd margay
$ cargo install --path .
03.

Run it

# audit the current directory
$ margay

# audit a specific path
$ margay ./my-project

# auto-correct everything
$ margay --fix

real usage

Wire it into your
workflow.

Machine-readable output

Pipe margay into jq, a custom reporter, or a GitHub Actions annotation step. The JSON shape mirrors the human report exactly. 

$ margay --json | jq '.issues[].path'
"./.env"
"./scripts/deploy.sh"
"./src/main.rs"

GitHub Actions

A permission bug never makes it back into main. Exits non-zero on findings, no flaky network calls, no config file needed. 

# .github/workflows/perms.yml
name: perms
on: [push, pull_request]
jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo install --git https://github.com/iamkorun/margay
      - run: margay
