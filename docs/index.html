margay watches your
file permissions.

A tiny Rust CLI that walks your project tree and patches bad chmod — missing exec bits, world-readable secrets, and source files accidentally marked executable.

see it run github
~/my-project 
$ margay

Sensitive files too open
  !! ./.env              0644 → 0600
  !! ./secrets/api.key   0664 → 0600

Shell scripts missing +x
  +x ./scripts/deploy.sh  0644 → 0744
  +x ./scripts/migrate.sh 0644 → 0744

Source files marked executable
  -x ./src/main.rs        0755 → 0644

✗ 5 issues found across 5 files
# run with --fix to patch all

$ margay --fix

$ margay
✓ no permission issues found

what margay sees

Three permission bugs that quietly ruin your week.

001 / exec bits

Scripts that forgot to be executable.

You wrote deploy.sh on Windows. CI runs it. CI dies with permission denied. margay flags every shell script missing the user-execute bit so you can patch them before the pager fires. 

$ margay
Shell scripts missing +x
  +x scripts/deploy.sh    0644 → 0744
  +x scripts/migrate.sh   0644 → 0744
$ margay
Sensitive files too open
  !! .env              0644 → 0600
  !! secrets/api.key   0664 → 0600

002 / loose secrets

Secrets sitting at 0644.

Every .env, *.key, *.pem, and id_rsa in your tree should be 0600 or stricter. margay finds them — then runs chmod for you with --fix.

003 / accidental exec

Source files marked executable.

A stray chmod -R 755 turns README.md and every *.rs into "executables." Harmless, embarrassing, and a permanent eyesore in git status. margay catches them. 

$ margay --fix
margay: fixed 5 issue(s)

$ margay
✓ no permission issues found

real usage

Wire it into your workflow.

Machine-readable output

Pipe margay into jq, a custom reporter, or a GitHub Actions annotation step. 

$ margay --json | jq '.issues[].path'
"./.env"
"./scripts/deploy.sh"
"./src/main.rs"

GitHub Actions

A permission bug never makes it back into main. Non-zero exit on findings, no flaky network calls. 

# .github/workflows/perms.yml
name: perms
on: [push, pull_request]
jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo install --git https://github.com/iamkorun/margay
      - run: margay
